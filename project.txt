# 4. OWASP ZAP integration logikasy

Realistically flow şeýle bolýar:

1. Admin target goşýar (URL)
2. Backend ZAP API-a request iberýär:

   * spider scan (crawl)
   * active scan (attack simulation)
3. ZAP results JSON/XML return edýär
4. Backend parse edýär:

   * alert list
   * risk level
   * URL mapping
5. Database saklanýar
6. Frontend report görkezýär
